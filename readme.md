# 工作记录（WorkLog）v3.3

Windows 7 免安装便携桌面应用：记事 + 待办 + 问题排查 + 项目号分类，单文件 exe 双击即用，零运行库依赖。
数据全部保存在 exe 同目录下的明文 JSON 文件里，按项目分文件存放。

## 功能

- **记事**：多行文本，可附带本地文件/文件夹超链接（支持多个），点链接打开**所在文件夹**；支持**置顶**（显示在列表最上面）
- **待办**：方框勾选完成、**三档优先级**（紧急 / 普通 / 非紧急）、截止日期、自动记录完成时间；
  支持**子待办**清单（卡片上直接勾选）；**待办列表每行两个网格**排布。
  **非紧急待办排在普通待办之后，且默认收纳**，点收纳条展开才全部显示
- **试机记录按天分组**：记事/已完成待办/问题等记录按天分组显示，每天之间有分割线，
  线上提示「下方是另一天的内容（日期）」
- **问题排查**：独立存储的问题档案——档案（描述/资料 + 链接）与纪实（处理过程 + 链接），
  卡片默认折叠点击展开；**是否解决**一键切换，未解决不受时间窗口限制、一直显示
- **多项目标记**：记事/待办/问题可同时挂多个项目号，保存时以第一个为主项目迁移文件
- **文件即项目**：分类与项目由 exe 同目录下的「分类-项目.json」文件决定，
  启动/打开面板时扫描目录重建；界面新建 = 创建对应文件；删除文件 = 删除项目
- **问题即文件**：问题排查存在 `问题排查/分类-项目-问题名称.json`，文件名即身份
- **项目管理**：分类 → 项目号两级结构（每行 4 个网格），按项目/分类筛选列表；
  **项目支持别名**（一个项目多个叫法，搜索/筛选按别名也能命中）
- **项目号下拉**：对话框打开时下拉默认收起；在项目号框输入文字才自动弹出匹配的
  候选面板，**点选某一项即立即确认选择**（面板随即收起，无需「完成」按钮）；
  要一次挂多个项目，再按 ▼（或继续输入）展开继续点，已选项目以标签显示、点 × 移除（勾选单个后自动收起，多选点 ▼）
- **最近 5 天窗口**：默认只显示最近 5 个自然日的记录，底部「加载更早记录」
  每次多显示 5 天；置顶记事 / 未完成待办 / 未解决问题不受窗口限制
- **筛选预选**：顶部筛选到具体项目时，新建记事/待办/问题默认带上该项目
- **全量搜索**：跨所有项目、跨时间模糊搜索（大小写不敏感、空格分词 AND、
  命中内容/项目名/别名/链接/问题名/档案/纪实）；顶部项目栏支持项目名搜索过滤
- **日期筛选**：起止日期区间，可与关键词组合
- **排序**：置顶记事 → 待办区（紧急 → 普通 → 非紧急收纳，按截止日期近优先）
  → 试机记录流（记事/已完成待办/问题，按时间倒序、同天相邻）
- **文字高亮**：正文里用 `**文字**` 或 `==文字==` 包住部分文字，即显示为
  加粗 + 荧光笔底色的高亮（各对话框正文下方有提示）
- **窗口可自由缩放**：拖标题栏移动、拖四边/四角改变大小，内容自适应重排
  （主窗口 616×800，最小 540×600）
- **子界面可拖拉**：记事/待办/问题/纪实/项目管理五个子界面右下角把手拖拉改大小，
  尺寸自动记住；居中显示
- **窗口控制按钮**：右上角最小化 / 最大化 / 关闭（最大化自动改直角，还原恢复圆角）
- **系统托盘**：最小化到右下角托盘驻留；双击托盘图标恢复主界面；
  右键菜单可「打开主界面 / 快速添加记事 / 快速添加待办 / 退出」；托盘图标与程序图标一致
- **右键菜单**：卡片上右键弹出（编辑/置顶/删除等），删除需二次确认
- **置顶开关**、记录删除两步确认、时间显示带星期

## 运行要求

- Windows 7 SP1 及以上 / Windows 8 / 10 / 11，64 位
- 无需安装，无需 .NET、VC++ 运行库

## 构建

需要 Go 1.20（Go 1.21+ 已不支持 Windows 7）：

```bash
# 在 Windows 上
go build -ldflags="-s -w -H windowsgui" -o 工作记录.exe .

# 在 Linux/macOS 交叉编译
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 \
  go build -ldflags="-s -w -H windowsgui" -o 工作记录.exe .
```

产物为单个 `工作记录.exe`（约 9.6 MB），DLL 与字体内嵌在 exe 内，
首次运行时释放到 `%APPDATA%\gohl\`。

## 数据格式

所有文件都在 exe 所在目录，纯文本 JSON（UTF-8）：

| 文件 | 内容 |
| --- | --- |
| `分类-项目.json` | 一个项目的全部记录；**文件名即分类与项目**，删除文件即删除该项目 |
| `未指定.json` | 未选择项目的记录 |
| `工作记录.json` | 界面设置（置顶、当前筛选） |
| `问题排查/分类-项目-问题名称.json` | 一条问题排查记录；**文件名即身份**，删除文件即删除该问题 |

文件名按**第一个 `-`** 拆分为「分类」和「项目」，例如 `研发-124.json` =
分类「研发」下的项目「124」；`研发-124-2.json` = 项目「124-2」。
界面新建时分类名里的 `-` 自动替换为 `_`，保证可反解。
目录扫描只认文件名含 `-` 的 `.json` 文件，其余文件不参与。
问题文件名三段为「项目 ID + 问题名称」，按已知项目 ID 最长前缀反解。

记录字段：

```json
{
  "id": "1700000000000123",
  "type": "note",              // note 记事 | todo 待办
  "text": "内容",
  "links": [{"name": "spec.pdf", "path": "D:\\docs\\spec.pdf"}],
  "projectId": "研发-124",      // = 文件基名，加载/保存时自动归一
  "time": "2026-10-22T10:30:00+08:00",
  "pinned": true,              // 记事置顶
  "urgent": true,              // 待办优先级：urgent 紧急 / low 非紧急 / 都不填=普通
  "low": false,
  "dueDate": "2026-10-25",
  "done": false,
  "doneTime": "2026-10-24T18:00:00+08:00",
  "subTodos": [{"id": "s1", "text": "子待办", "done": false}]
}
```

问题排查文件字段：

```json
{
  "id": "研发-124-屏幕闪烁", "name": "屏幕闪烁", "projectId": "研发-124",
  "time": "2026-10-22T10:00:00+08:00",
  "resolved": false, "resolvedTime": null,
  "profileText": "问题描述/资料",
  "profileLinks": [{"name": "日志", "path": "D:\\logs"}],
  "log": [{"id": "e1", "text": "纪实", "links": [], "time": "2026-10-22T15:00:00+08:00"}]
}
```

写入采用「临时文件 + 原子替换」，断电不会写坏；解析失败的文件会改名为 `.bak` 保留。

## 开发注意事项（HTMLayout 踩坑记录）

1. **中文乱码**：内嵌 HTML 必须带 UTF-8 BOM，且正文中文需转成十进制 HTML 实体
   （`asciiSafeHTML`）——否则中文系统按 GBK 代码页解析 UTF-8 字节，静态文字全变问号。
2. **字体名**：内嵌字体的真实 family 名是 `Alibaba PuHuiTi 2.0`（英文），
   不是「阿里巴巴普惠体 2.0」，CSS 写错会静默回退。
3. **原生 checkbox 不可见**：HTMLayout 对 `<input type="checkbox">` 只算尺寸不画外观，
   必须用 `behavior: button` 的 div 自绘。
4. **`✓` 缺字形**：中文字体无 U+2713，用 `√`（U+221A）代替。
5. **`1*` 弹性宽度**：在嵌套 `flow: vertical` 容器上会吃满剩余空间、忽略兄弟元素宽度，
   因此卡片主体使用固定内容宽度。
6. **拖动窗口**：元素加 `-gohl-drag` 属性即成为拖动区；已修改 gohl 的命中测试，
   使链上有 `data-act` 或输入控件的元素不触发拖动，保证按钮可点。
7. **窗口缩放重排**：HTMLayout 不会因外部改尺寸自动重排，需在尺寸变化时
   调 `RootElement(hwnd).Update(...)`；gohl 的 `SetTimer` 是一次性的，回调里要重新注册。
8. **`TrackPopupMenuW` 不存在**：user32 里只有 `TrackPopupMenu`（无 W/A 后缀），
   `NewProc("TrackPopupMenuW")` 惰性解析时直接 panic。托盘菜单相关 API 用前先
   GetProcAddress 验证名字。
9. **前台激活不能卡主线程**：`AttachThreadInput + SetForegroundWindow` 在前台线程
   无响应时（如锁屏的 winlogon）会长时间阻塞，把窗口消息 loop 卡死（定时器全停）。
   必须放在 goroutine 里执行并加等待超时；`SetForegroundWindow` 目标线程 ID 要用
   main() 里 `GetCurrentThreadId` 捕获的主线程 ID（gohl 已 LockOSThread）。
10. **最大化要清圆角区域**：frameless 窗口设了 SetWindowRgn 圆角，SW_MAXIMIZE 后
    区域不跟着变会把四角切掉；最大化时 `SetWindowRgn(hwnd, 0, 1)` 清除区域，
    还原时重新 apply。尺寸变化由 watchResize 定时器兜底。

11. **date/time 输入框取值赋值**：gohl 的 `SetValue` 走 SET_TEXT_VALUE，
    date/time 行为不处理该方法（GET 也不处理），赋值唯一可靠做法是
    重建元素让 `value` 属性随元素初始化生效；读取用 `Attr("value")`。
12. **锁屏下截图不可信**：锁屏会话里 PrintWindow（含 RENDERFULLCONTENT）
    会按缩放渲染且大片区域 alpha 缺失，截图看起来"裁切"其实布局正常；
    用进程内 `root.ContentBox()` 对比客户区尺寸才是可靠的取证方式。

## 版本

- **v3.3**：①**彻底修复截止时间等所有日期/时刻无法修改**——根因是 HTMLayout 的
  `type=date/time` 控件选值后无法读回（GET_TEXT_VALUE 不支持、value 属性停在初始值），
  改为**文本框录入**（支持 2026-10-25 / 2026/10/25 / 20261025、17:00 / 1700 等格式自动规范化），
  记事/待办/问题/纪实/日期筛选全部生效；②左上角显示**程序名 + 版本号**；
  ③底部按钮**区分配色**（记事绿 / 待办橙 / 问题排查红 / 项目灰蓝）；
  ④补齐**文字高亮**（`**文字**` 或 `==文字==` → 加粗 + 荧光笔底色，对话框内附使用提示）
- **v3.2**：修复两处问题——①待办**截止时间**修改后不生效：HTMLayout 的 date/time 输入
  `value` 属性在 change 事件后会回退陈旧初值，改为在编辑当下把值捕获进程序、保存时读捕获值；
  ②卡片文件链接仍直接打开文件、且中文路径乱码：改用显式按钮处理（不走 `<a href>` 超链接
  默认行为），点击**统一打开文件所在文件夹**、不再用关联程序打开文件
